ภายในศูนย์
ปลายทางเดียวต่อครั้ง · เวชระเบียน / คัดกรอง / ห้องแพทย์ / พยาบาลหลังตรวจ
ศบส. อื่น
ในสำนักอนามัย → แวะห้องการเงินปิดสิทธิก่อน
โรงพยาบาล
นอกสำนักอนามัย → ใบส่งตัว + ความยินยอม Health Link → การเงิน
กรณีพิเศษ
  • ติ๊ก "ส่งต่อต่างประเทศ" → ไม่ต้องเลือกโรงพยาบาล · ใบส่งตัวภาษาอังกฤษ ("แปลเป็นภาษาอังกฤษ")
  • ส่งต่อนักสังคมสงเคราะห์ → ต้องเลือก "เหตุผล / ข้อควรระวัง" อย่างน้อย 1 ข้อ
  • ติ๊ก "ส่งปรึกษาผ่าน Telemedicine" ในป๊อปอัปนี้ได้ · การส่งต่อยังไปด้วย
มักสับสน
  • เขียน "ปรึกษาแพทย์เฉพาะทาง" ในช่องความต้องการของใบส่งต่อ = ยังเป็น ส่งต่อ
  • ปลายทางกับแพทย์ที่เลือกจากขั้นก่อน แสดงเป็นข้อความ ไม่ให้เลือกซ้ำ

4 · คลินิกพิเศษ: ใครทำ และขั้นของแพทย์

(C) = ขั้นความยินยอม ซ่อนไปไว้ใน ⋮ ถ้าเคยลงนามแล้ว · "ตรวจสอบข้อมูล" มีเฉพาะเบาหวาน · ความดัน · ทันตกรรม

คลินิกพยาบาลคัดกรองพยาบาลหลังตรวจขั้นของแพทย์ขั้นสุดท้ายทะเบียนบทบาทอื่น

ทุกคลินิกเหมือนกัน

พยาบาลคัดกรอง
(C) → แบบประเมิน → เลือกคลินิกและแพทย์ → "บันทึกและส่งต่อ" (ป๊อปอัปเติมคลินิก/แพทย์ที่เลือกให้แล้ว)
พยาบาลหลังตรวจ
/exit/record → [สถานะความยินยอม · ยกเว้น OPD · แพทย์แผนไทย · เบาหวาน · ความดัน] → ตรวจร่างกายและวินิจฉัย → CPOE → เอกสาร/ใบรับรองแพทย์ → "บันทึกและส่งกลับ"
ขั้นหลัง CPOE
ทุกคลินิกยกเว้นทันตกรรม มี "แผนการดูแลรักษา" ต่อจาก CPOE
ท้ายฟอร์ม
"ตรวจสอบความครบถ้วน (ขาด N)" มีทุกหน้า ไม่ใช่ขั้น

5 · งานบำบัดยาเสพติด

แผนภาพอยู่ในข้อ 1 (เลือก "งานบำบัด") · 4 คลินิก: ก้าวใหม่ · เมทาโดน/BNX · บุหรี่ · แอลกอฮอล์ · หลังแพทย์วางแผน ไปได้ทางเดียว

สถานะในคอลัมน์ "การส่งต่อ / สถานะ"
ยังไม่ขึ้นทะเบียนรักษาในคลินิกรอปลายทางรับบ้านพิชิตใจจำหน่ายแล้ว
จำนวนครั้งตามระดับ (ก้าวใหม่ ใช้ทุกคลินิก)
ผู้ใช้
1–2 ครั้ง
ผู้เสพ
4–8 ครั้ง
ผู้ติด
8–16 ครั้ง
After Care
4–7 ครั้ง/ปี
กติกา
  • ผู้รับบริการใหม่ ขึ้นทะเบียนได้ทุกบทบาท · แก้ทะเบียนเฉพาะแพทย์
  • ยังไม่ขึ้นทะเบียน = ยังไม่มีความคืบหน้าคอร์ส (0%)
  • ครั้งที่บำบัดนับจากครั้งแรกของคอร์ส ไม่นับวันพบแพทย์
  • จบการคัดกรองได้เมื่อทำ OAS แล้ว

6 · สถานะคิว

สถานะเดียว = ความหมายเดียวในทุกคิว · ตัวเลขในแท็บ = ตัวเลขในเมนูข้าง

ชุดมาตรฐาน (คิวผู้รับบริการ)

ความหมายป้ายแท็บ
รอรอตรวจ รอคัดกรองคิววันนี้
อยู่ห้องยา (คัดกรอง)รอห้องยาประเมินคิววันนี้
กำลังทำกำลังตรวจ กำลังคัดกรองคิววันนี้
ร่างบันทึกไม่เสร็จคิววันนี้
เสร็จตรวจเสร็จแล้ว คัดกรองแล้วตรวจเสร็จแล้ว
นัดแต่ยังไม่มานัดแล้วยังไม่มา—
ยกเลิก (แถวยังอยู่)ยกเลิกนัดยกเลิกนัด

คิวของแผนก (คำของแผนกเอง)

หลังตรวจ
รอส่งกลับ → กำลังส่งกลับ → ส่งต่อแล้ว · ยกเลิกคิว
คิวรวม
รอแพทย์รับเคส → รับเคสแล้ว
ห้องยา
รอเภสัชยืนยันรายการยา → รอชำระเงิน/ปิดสิทธิ → พร้อมจ่ายยา → จ่ายแล้ว / จ่ายบางส่วน · ไม่มารับยา · มีปัญหา · ยกเลิก
การเงิน
รอชำระเงิน → ชำระแล้ว · ยกเลิกใบเสร็จ
แล็บ
รอรับคำขอ → รอเก็บ/รับตัวอย่าง → กำลังตรวจ → (ส่งตรวจภายนอก) → รอรับรองผล → รายงานผลแล้ว · ปฏิเสธตัวอย่าง · รอเจาะซ้ำ
เอกซเรย์
รอรับรายการ → (นัดตรวจ) → รอดำเนินการ → รอบันทึกผล → บันทึกผลแล้ว → ยืนยันผล
ศูนย์คิว
รอเรียก → กำลังเรียก → กำลังให้บริการ → เสร็จสิ้น · พักคิว · ข้ามคิว · ยกเลิก

7 · รอตัดสินใจ และจุดที่เดโมยังไม่ตรง

ทีมใช้ส่วนนี้คุยต่อ ตอบเป็นเลขข้อได้

คำถามที่ยังไม่มีคำตอบ

ข้อคำถามตัวเลือก
Q3หน้าบันทึกงานสังคมสงเคราะห์ถาวร ใช้แบบไหนก. หน้าเฉพาะ (จบที่ ส.ส.2)
ข. เทมเพลตคลินิก

ตกลงแล้ว แต่เดโมยังไม่ส่งต่อให้อัตโนมัติ

  • Kiosk → เวชระเบียน ยังไม่เชื่อม
  • เวชระเบียน → คัดกรองกลาง ยังส่งเฉพาะข้อมูล ไม่มีแถวในคิวคัดกรอง
  • คัดกรองกลาง เลือกแพทย์ระบุชื่อ → ยังไม่ขึ้นในคิวแพทย์
  • คัดกรองคลินิก → แพทย์คลินิก ยังไม่เชื่อม
  • แพทย์จบ → พยาบาลหลังตรวจ เข้าคิวอัตโนมัติเฉพาะคนที่มีคลินิกลำดับที่ 2 (คนอื่นยังเป็นข้อมูลตัวอย่าง)
  • CPOE แล็บ / เอกซเรย์ → คิวแผนก ยังไม่เชื่อม (EKG · CXR เชื่อมแล้ว)
  • สถานะ "รอห้องยาประเมิน" ในคิวคัดกรอง ยังไม่แสดง
  • กายภาพบำบัด · สังคมสงเคราะห์ จบแล้วยังไม่เปิดป๊อปอัปส่งต่อ
