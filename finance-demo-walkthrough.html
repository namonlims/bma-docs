ส่วนที่ 1 · งานการเงิน (/finance)

บทบาท ฝ่ายการเงิน · ทุกขั้นเริ่มจากเมนูซ้าย "การเงิน"

1. ภาพรวมคิวชำระเงิน

ฝ่ายการเงินมติ 2.1.5 · 2.1.9 · 2.2.5 · 2.2.6
  1. ชี้การ์ดสรุป 4 ใบ: รอชำระเงิน · ชำระแล้ววันนี้ · ยอดค้างชำระ (N ราย · ทุก Visit) · ใบเสร็จที่ยกเลิก
  2. ชี้แท็บบน 8 แท็บ แล้วอยู่ที่ คิวชำระเงิน › รอชำระเงิน
  3. ชี้ตัวกรอง จุดบริการ: (ทั่วไป · ทำแผล · ฉีดยา · งานบำบัดยาเสพติด)
  4. ชี้แถว F001 สองแถว: "Visit 1 จาก 2" และ "Visit 2 จาก 2" ใต้ VN
  5. ชี้ไอคอนเงินสีส้มหลังชื่อ + "ค้างเก่า 3 ครั้ง · 495" + ปุ่ม ดูรายการค้างชำระ
  6. ชี้แถว F004: ปุ่ม ชำระเงิน มีกุญแจ → ชี้เมาส์ค้างให้เห็นชื่อผู้ที่เปิดบิลอยู่
  7. กด ⋮ ของแถวใดก็ได้ ให้เห็นเมนู: ขอลดหย่อน · ดูประวัติการขอลดหย่อน · ดูรายการค้างชำระ · ยกเลิกคิว
พูดว่าคลินิกตรวจโรคทั่วไป เบาหวาน ความดัน ใช้ Visit เดียวกัน คลินิกอื่นแยก Visit และ 1 Visit = 1 บิล · ยอดค้างชำระแจ้งเตือนทุกจุดแต่ไม่บล็อกการรับบริการ · บิลที่คนอื่นเปิดอยู่จะถูกล็อกกันรับเงินซ้ำ

2. รับชำระเงินสดและออกใบเสร็จ (F001)

ฝ่ายการเงินHN 67-00001 · VN 69-00001มติ 2.1.1 · 2.1.2 · 2.1.6 · 2.2.2
  1. แถว F001 (VN 69-00001) กดลำโพง เรียกคิว → ปุ่ม "ชำระเงิน" เปลี่ยนเป็นปุ่มเขียวเข้ม
  2. กด ชำระเงิน → ป๊อปอัป "ยืนยันรับผู้ป่วย" (ติ๊ก มารับยาแทน / มาฟังผล) → ยืนยัน
  3. หน้า "ชำระเงิน" ขั้น 1 รายการค่าใช้จ่าย: ชี้แถบ 4 ขั้นใต้การ์ดผู้ป่วย
  4. กล่องส้ม "มียอดค้างชำระ" → ดูรายการ → เห็น 3 Visit (11 ต.ค. ฿60 · 22 ก.ย. ฿165 · 29 ส.ค. ฿270) ติ๊กเก็บพร้อมบิลนี้ได้ (ออกใบเสร็จแยก ลงวันที่วันนี้)
  5. ตารางรายการ: ชี้ Checkbox (เอาติ๊กออก = ไม่เก็บครั้งนี้ คงค้างไว้) · กดลูกศรหน้าแถว "ค่าตรวจทางห้องปฏิบัติการ" ให้เห็นรายละเอียด
  6. ฝั่งขวา "ยอดที่ต้องชำระ" ค่ารักษา ฿1,460 · เบิกได้ -฿1,010 · ยอดเงินที่ต้องชำระ ฿450 → ดำเนินการชำระเงิน
  7. ขั้น 2 ตรวจสอบสิทธิ: ชี้ 2 กล่อง "สำหรับผู้ที่ใช้สิทธิ" (บัตรประชาชน | ThaiD) / "สำหรับผู้ที่ไม่ใช้สิทธิ" (ชำระเงินเอง) → ยืนยันสิทธิและดำเนินการชำระเงิน
  8. ขั้น 3: ชี้ 4 วิธีชำระ (บัตรเครดิตกดไม่ได้เพราะยอดต่ำกว่า 1,000) → เลือก เงินสด ใส่ 500 → เงินทอน 50 บาท → รูปแบบใบเสร็จ อิเล็กทรอนิกส์ / กระดาษ → บันทึกและออกใบเสร็จ
  9. ขั้น 4 ใบเสร็จ: พิมพ์ใบเสร็จ (ฉบับจริง) → หน้า "ตัวอย่างก่อนพิมพ์" (แบบ-01 ลายน้ำ "ต้นฉบับ") → พิมพ์ใบเสร็จ (ต้นฉบับ) → ปุ่มเปลี่ยนเป็น "พิมพ์สำเนา"
  10. เซ็น "ลายเซ็นผู้รับบริการ" → บันทึกและส่งต่อ → ป๊อปอัปส่งต่อ (เหมือนแผนกอื่น)
พูดว่าชำระได้ 4 ช่องทางตามมติ · บัตรเครดิตขั้นต่ำ 1,000 บาทบวกค่าธรรมเนียม 1% · ที่ไม่ใช่เงินสดต้องกด "ตรวจสอบการรับเงิน" ก่อนออกใบเสร็จ · ฉบับจริงพิมพ์ได้ครั้งเดียว ครั้งต่อไปเป็นสำเนา

3. ยอด ฿0 และใบยานอก (F003)

ฝ่ายการเงินHN 67-00003 · ข้าราชการมติ 2.1.9
  1. แถว F003 → ชำระเงิน → ป๊อปอัปยืนยันรับ: "มารับยาแทน" ติ๊กมาให้แล้ว พร้อม "บันทึกโดย …" → ยืนยัน
  2. ดำเนินการชำระเงิน → ยืนยันสิทธิและดำเนินการชำระเงิน
  3. เห็นกล่อง "ไม่มียอดบริการที่ต้องชำระ" (ไม่มีช่องวิธีชำระ เลือกแค่รูปแบบใบเสร็จ) → บันทึกและออกใบเสร็จ
  4. หัวใบเสร็จมีปุ่ม พิมพ์ใบยานอก (เฉพาะสิทธิข้าราชการ กรมบัญชีกลาง + ข้าราชการ กทม. ที่มีรายการยา)

4. บัตรทองยังไม่ปิดสิทธิ (F005)

ฝ่ายการเงินHN 67-00005 · บัตรทองมติ 2.1.6 · 2.1.7
  1. ชี้แถว F005: สถานะสีแดง "ค้างชำระ · ยังไม่ปิดสิทธิ" + ใต้สถานะยา "รับยาไม่ได้ · รอปิดสิทธิ"
  2. ⋮ → ปิดสิทธิ (บัตรประชาชน / ThaiD / สปสช.)
  3. เลือกช่องทาง (บัตรประชาชน · ThaiD · ระบบ สปสช. กรณีลืมบัตร) → ยืนยันตัวตน → ยืนยันปิดสิทธิ
  4. "ปิดสิทธิเรียบร้อย · รับยาได้แล้ว" → ตกลง → แถวเปลี่ยนเป็น "รอชำระเงิน"
พูดว่าห้องยาจ่ายยาไม่ได้จนกว่าจะปิดสิทธิ (ห้องยาคิว P-052 คือคนเดียวกัน)

5. ยกเลิกและแก้ไขใบเสร็จ

ฝ่ายการเงินมติ 2.1.3 · 2.1.4

ยกเลิก (ต่อจากข้อ 3 ได้เลย)

  1. หน้าใบเสร็จ → ยกเลิกใบเสร็จ (ปุ่มแดงซ้ายล่าง)
  2. เลือกเหตุผล เช่น "ระบุสิทธิผิด" → ยืนยันการยกเลิกใบเสร็จ → การ์ด "ใบเสร็จที่ยกเลิก" เพิ่ม 1

แก้ไข

  1. แท็บ ทะเบียนรายรับ → แถวใบเสร็จ RE69-1064 → ไอคอนดินสอ "แก้ไขใบเสร็จ"
  2. ซ้าย "ข้อมูลใบเสร็จ" แก้ไม่ได้ (ยอดผิดต้องยกเลิกแล้วออกใหม่) · ขวาแก้วิธีชำระเงิน + ต้องเลือกเหตุผล → บันทึกการแก้ไข
  3. ชี้ใบเสร็จที่มีรูปกุญแจ: สร้างโดยคนอื่น แก้ไม่ได้ (ชี้เมาส์ค้างให้เห็นเหตุผล)
พูดว่ายกเลิกเองได้ภายในวันเดียวกันและก่อนตัดยอด · ข้ามวันหรือตัดยอดแล้วต้อง "ขออนุมัติยกเลิกใบเสร็จ" (ไปที่หัวหน้างานการเงินในแท็บคำขออนุมัติ) · แก้บิลได้เฉพาะคนสร้างบิล

6. ลดหย่อนไม่เกิน ฿500 → นักสังคมสงเคราะห์ (F015)

ฝ่ายการเงินนักสังคมสงเคราะห์ศูนย์HN 67-00015มติ 2.1.9

ฝั่งการเงิน · ขอ

  1. แถว F015 (หน้า 2) → ⋮ → ขอลดหย่อน (หรือติ๊ก "ขอลดหย่อนค่าบริการทางการแพทย์" ในหน้าบิล)
  2. ระบบใส่ 100% ให้ · สลับ % | บาท ได้ · บรรทัด "ผู้อนุมัติ: นักสังคมสงเคราะห์" → ส่งนักสังคมสงเคราะห์
  3. แบบฟอร์มที่ 1 "ส่งเคสลดหย่อน": เลือก "ผู้ที่ได้รับมอบหมาย" (ไม่บังคับ) · เลือกเหตุผล · เซ็นชื่อผู้ส่ง → ส่งเคสลดหย่อน → "ส่งคำขออนุมัติเรียบร้อย"
  4. สถานะในบิลและคิว = "รอนักสังคมอนุมัติลดหย่อน" (สีเหลือง)

ฝั่งนักสังคมสงเคราะห์ · ประเมิน

  1. สลับบทบาท → นักสังคมสงเคราะห์ศูนย์ → เมนู แดชบอร์ด (สิ่งที่ต้องดำเนินการ)
  2. แถว "อนุมัติลดหย่อนค่ารักษา ฿235" → ทำแบบประเมิน
  3. แบบฟอร์มที่ 2: ตอบข้อ 1–5 (ข้อละ 1 ตัวเลือก) + ข้อ 6.1–6.8 (มี/ไม่มี) → ระบบรวมคะแนน 13–35 และเลือกร้อยละตามเกณฑ์ให้
  4. ถัดไป: แบบแจ้งผลการพิจารณา → แบบฟอร์มที่ 3: เลือก "ได้สัมภาษณ์ ผู้ป่วย" · กด "ลายเซ็นหลัก" → ส่งผลให้เจ้าหน้าที่การเงิน

กลับฝั่งการเงิน · รับชำระ

  1. สลับบทบาท → ฝ่ายการเงิน → เปิดบิล F015: บรรทัด "ได้รับการลดหย่อนค่าบริการทางการแพทย์ -฿…" หักให้อัตโนมัติ · ป้าย "นักสังคมอนุมัติแล้ว" · ดูรายละเอียด เห็นแบบแจ้งผล
พูดว่าไม่มีส่วนลดทั่วไปแล้ว ลดได้ทางเดียวคือขอลดหย่อน · ทุกเคสผ่านนักสังคมสงเคราะห์ก่อน · คะแนน 29–35 ลดได้มากกว่า 75% · 21–28 ลด 50–75% · 13–20 ลดไม่เกิน 50% · อนุมัติบางส่วน ยอดที่เหลือยังเป็นหนี้ค้างจนกว่าจะจ่าย

7. ลดหย่อนเกิน ฿500 → ผอ.ศูนย์ (F012)

ฝ่ายการเงินนักสังคมสงเคราะห์ศูนย์ผอ.ศูนย์บริการสาธารณสุขHN 67-00012 · ฿2,000
  1. การเงิน: แถว F012 (หน้า 2) → ⋮ → ขอลดหย่อน · บรรทัดผู้อนุมัติ = "นักสังคมสงเคราะห์ประเมิน → ผอ.ศูนย์อนุมัติ (เกิน ฿500)" → ส่งเหมือนข้อ 6
  2. นักสังคม: ทำแบบประเมิน (เดโมเลือกกลาง ๆ ได้ 24 คะแนน = 75% = ฿1,500) → แบบฟอร์มที่ 3 ปุ่มเปลี่ยนเป็น ส่งผล ผอ.ศูนย์อนุมัติ
  3. สลับบทบาท → ผอ.ศูนย์บริการสาธารณสุข → แดชบอร์ด "รายการที่ต้องอนุมัติ" → แถว "พิจารณาอนุมัติ ลดหย่อนค่ารักษา นายวิชัย รุ่งเรือง · 1,500 บาท" → อนุมัติ → ในกล่องรายละเอียดกด อนุมัติ อีกครั้ง
  4. กลับการเงิน: แท็บ ลดหย่อน แถว 67-00012 = "ผอ.ศูนย์อนุมัติแล้ว" · บิลเหลือยอด ฿500
เคส F004 (ภูริ ฿850) ในข้อมูลตั้งต้นแสดง "รอ ผอ.ศูนย์อนุมัติ" แต่ไม่ขึ้นในรายการของ ผอ. — เดโมสาย ผอ. ให้สร้างเคสใหม่ด้วย F012 ตามขั้นข้างบน

8. ค้างชำระ

ฝ่ายการเงินมติ 2.1.5 · 2.1.6
  1. แท็บ ค้างชำระ: 1 แถวต่อ 1 คน · ขวาบนตาราง "ยอดค้างชำระรวม (41 ราย · 79 Visit)"
  2. กดลูกศรหน้าแถว 67-00001 → กางดูทีละ Visit (วันที่ · VN · คลินิก · ยอด · รับชำระ)
  3. รับยอดค้างชำระ ▾ → "เลือกรายการที่ต้องการรับยอดชำระ" → เลือก 1 Visit → เข้าหน้าบิลเหมือนข้อ 2
  4. หลังจ่าย Visit หนี้แล้วยังมีค้างอีก ตอน "บันทึกและส่งต่อ" ระบบถาม "ยังมียอดค้างชำระอีก N Visit" (จ่ายต่อ หรือ "ไว้ชำระวันหลัง")
พูดว่าไม่มีการผ่อนจ่าย รับทีละ Visit เต็มจำนวน · ป้ายค้างชำระเห็นทุกหน้าทุกบทบาท (worklist · การ์ดผู้ป่วย · เวชระเบียน) จ่ายแล้วป้ายหายเอง

9. ทะเบียนรายรับ · ตรวจสอบใบเสร็จ · คำขออนุมัติ · ลดหย่อน

ฝ่ายการเงิน
  1. ทะเบียนรายรับ: กราฟ "รายรับแยกตามช่องทางการชำระเงิน" + "ความครบถ้วนการรับชำระ" · มุมมอง รายผู้รับบริการ | รายคลินิก | รายผู้รับเงิน · นำส่งออกรายงาน
  2. ตรวจสอบใบเสร็จ: แท็บสถานะ ทั้งหมด · ปกติ · แก้ไขแล้ว · ยกเลิกแล้ว · ดูใบเสร็จ = ดูอย่างเดียว
  3. คำขออนุมัติ: รออนุมัติ · อนุมัติแล้ว · ไม่อนุมัติ · ตัวกรอง "ประเภท:" (ลดหย่อน · ยกเลิกใบเสร็จข้ามวัน) · การเงินอนุมัติลดหย่อนเองไม่ได้ เห็นแค่สถานะ
  4. ลดหย่อน: ตารางเคสทั้งหมด ตัวกรอง "สถานะ:" + "ผู้อนุมัติ:"

10. เมนูพิมพ์ ▾ (หัวหน้า /finance)

ฝ่ายการเงินมติ 2.1.8
  1. กด พิมพ์ ▾ ข้างปุ่ม "รายงาน" → 5 รายการ
  2. พิมพ์ใบสรุปยอดการรับชำระเงิน — ตัดยอดใบเสร็จวันนี้ของคนที่ login · มีกล่องยืนยัน "ตัดยอดและพิมพ์" · อย่ากดยืนยันตอนเดโม ถ้ายังจะโชว์การยกเลิกใบเสร็จต่อ
  3. พิมพ์ใบสรุปการเงินรายวัน — ทุกจุดรับเงินของวันนี้
  4. พิมพ์ใบสรุปการนำฝากเงิน — รอบ 16:00 เมื่อวาน ถึง 15:59 วันนี้
  5. พิมพ์ใบเคลมประกัน — ตารางผู้ป่วยประกันเอกชนวันนี้ (F010 ไทยประกันชีวิต · F018 เอไอเอ) → พิมพ์
  6. พิมพ์ใบส่งเบิกประกันสังคม — 1. เลือกโรงพยาบาลคู่สัญญาหลัก (ตากสิน · หลวงพ่อทวีศักดิ์ · สิรินธร · ราชพิพัฒน์ · เจริญกรุงประชารักษ์ · โรงพยาบาลอื่น) → 2. รายชื่อของโรงพยาบาลนั้น → พิมพ์ (แต่ละโรงพยาบาลใช้แบบฟอร์มของตัวเอง)

11. โควตาตรวจสิทธิ สปสช.

ฝ่ายการเงินมติ 2.2.1
  1. หัวหน้า กดข้อความ โควตา สปสช. วันนี้ 79 / 5,000 คน ›
  2. ป๊อปอัป "ตรวจสอบสิทธิการรักษา" → กดแถวผู้ป่วย → ผลตรวจสิทธิ: ปุ่มตรวจกับ สปสช. · กรมบัญชีกลาง · ประกันสังคม + ลำดับการใช้สิทธิ
พูดว่าตรวจซ้ำคนเดิมในวันเดียวกันใช้ผลเดิม ไม่นับโควตา

12. REP / Statement · ผู้รับบริการทั้งหมด · อัตราค่ารักษา · รายงาน

ฝ่ายการเงินมติ 2.1.9 · 2.2.7
  1. REP / Statement: ปุ่ม ประวัติการนำเข้า · บันทึกรับเงินจากหน่วยงาน (ประกันสังคม สนพ. · ต้นสังกัด ที่เป็นเอกสาร) · นำเข้า REP · นำเข้า Statement · ตาราง "รายการที่นำเข้า" มีคอลัมน์ "กระทบยอด" (ตรงกับระบบ · ยอดไม่ตรง · ไม่พบในระบบ) · แท็บ "บันทึกข้อผิดพลาดรายบรรทัด"
  2. ผู้รับบริการทั้งหมด: ดูอย่างเดียว · กดแถวกาง "ประวัติการรับบริการ" (ไม่มีข้อมูลการรักษา)
  3. เมนูซ้าย อัตราค่ารักษาพยาบาล: แท็บ อัตราค่าบริการ · รายการเบิกได้ตามสิทธิ · รายการค่าใช้จ่ายแยกตามสิทธิการรักษา · ยา/เวชภัณฑ์ที่ราคาเปลี่ยน กดลูกศรดู "ประวัติการเปลี่ยนราคา"
  4. หัวหน้า รายงาน → หน้า "รายงานการเงิน" (รายรับ · รายจ่าย · แยกช่องทาง · แยกหมวด · ทะเบียนคุมลูกหนี้ 5 สิทธิ)

13. ปิดสิทธิ / ชำระที่คลินิกยาเสพติด (F019)

แพทย์เวชศาสตร์การเสพติด (คลินิกโปรแกรมก้าวใหม่)HN 67-00019
  1. สลับบทบาท → แพทย์เวชศาสตร์การเสพติด (คลินิกโปรแกรมก้าวใหม่) → หน้า /clinic/addiction
  2. แถว 67-00019 → ⋮ → ปิดสิทธิ / ชำระเงิน
  3. ป๊อปอัปแสดงทุกบิลของ HN: Visit ของงานบำบัด กด ปิดสิทธิ ได้ที่คลินิก · Visit อื่นขึ้น "ชำระที่ห้องการเงิน"
พูดว่าบิลงานบำบัดที่ยอด ฿0 ไม่ต้องออกใบเสร็จ ปิดสิทธิแล้วจบ · คลินิกอื่นยังต้องไปห้องการเงิน

ส่วนที่ 2 · สิทธิและการเบิกจ่าย (/rights)

บทบาท ฝ่ายการเงิน → เมนูซ้าย "สิทธิและการเบิกจ่าย" · ข้อมูลชุดนี้เป็นครั้งบริการที่ Close Visit แล้ว 17 ครั้ง

14. คิวส่งเบิกและหน้าตรวจสอบ

ฝ่ายการเงินมติ 2.2.2 · 2.2.4 · 2.2.5 · 2.2.6
  1. ชี้การ์ดสรุป 7 ใบ: รอตรวจสอบ · ยืนยันแล้ว · ต้องแก้ไข · รอแพทย์ยืนยัน ICD-10 · สปสช. ปฏิเสธ · รออุทธรณ์ · Close Visit ทั้งหมด
  2. แท็บ ส่งเบิก › คิวส่งเบิก · ตัวกรอง วันที่รับบริการ (ไม่เกิน 1 เดือน) · คลินิก · รูปแบบการส่งเบิก (Digital Platform | เอกสาร) · ประเภทบริการ OP/PP · กิจกรรม · สิทธิ · สถานะ
  3. ชี้คอลัมน์ "ส่งได้ถึง" (1 ต.ค. ปีงบถัดไป · เหลือ ≤ 30 วันสีส้ม · เลยแล้วสีแดง)
  4. ชี้แถว 69-00003 มีกุญแจ = มีคนรับงานแล้ว (น.ส.พิมพ์ชนก ส่งเบิก) คนอื่นเปิดได้แต่อ่านอย่างเดียว
  5. แถว 69-00001 → ตรวจสอบ → หน้า "ตรวจสอบข้อมูลส่งเบิก": ข้อมูลการรับบริการ · คลินิก/แพทย์ · ICD10 · ICD9CM · ยอดค่าใช้จ่ายและการเรียกเก็บ
  6. ล่างสุด ยืนยัน 2 ส่วน: ยืนยันข้อมูลการรักษา + ยืนยันรหัสโรค → ครบทั้งคู่ถึงจะเข้าไฟล์ส่งเบิก · บันทึกข้อมูลส่งเบิก

15. แก้ ICD-10 ต้องให้แพทย์ยืนยัน · ยื่นอุทธรณ์

ฝ่ายการเงินแพทย์มติ 2.2.3
  1. หน้า 2 ของคิว แถว 69-00016 สถานะ "รอแพทย์ยืนยัน ICD-10" (เจ้าหน้าที่เพิ่ม E78.5)
  2. สลับบทบาท → อายุรแพทย์ (คลินิกตรวจโรคทั่วไป) → เปิด /rights/submit/rv-016 (เมนู สิทธิและการเบิกจ่าย → แถว 69-00016 → ตรวจสอบ)
  3. แถบเตือน "รอแพทย์ยืนยันการแก้ไข ICD-10 · เดิม I10 → ใหม่ I10, E78.5" → อนุมัติ หรือ ไม่อนุมัติ (ไม่อนุมัติ = รหัสกลับเป็นเดิม)
  4. แถว 69-00009 "สปสช. ปฏิเสธ" → เปิดดู → ยื่นอุทธรณ์ ใส่เหตุผล → กลายเป็น "รออุทธรณ์" (ตัวอย่างที่ยื่นแล้ว = 69-00010)
พูดว่าเจ้าหน้าที่เบิกจ่ายแก้รหัสได้ แต่ต้องให้แพทย์ผู้ตรวจยืนยันก่อน ระหว่างรอยืนยันรหัสไม่ได้ · เฉพาะบทบาทแพทย์เห็นปุ่มอนุมัติ

16. ส่ง e-Claim · Dashboard · รายงาน

ฝ่ายการเงินมติ 2.2.8
  1. แท็บ เชื่อมต่อ e-Claim / สปสช.: ป้ายเขียว "e-Claim เชื่อมต่อแล้ว" · ครั้งบริการที่ยืนยันแล้ว 7 รายการ → ส่ง e-Claim ทีละแถว หรือ ส่งรายการที่พร้อมทั้งหมด
  2. แท็บ Dashboard: ยอดเรียกเก็บ · ส่วนเงินสดจากผู้รับบริการ · คิวส่งเบิกตามสถานะ · ยอดเรียกเก็บแยกตามผู้จ่าย · รายเดือนแยกตามสิทธิ · ยอดส่งเบิกเทียบยอดได้รับ
  3. แท็บส่งเบิก › สรุปตามรอบส่งเบิก: กดแถวรอบกางดูรายการ
  4. หัวหน้า รายงาน → รายงานสิทธิและการเบิกจ่าย
