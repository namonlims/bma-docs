UX writing · ปลั๊กอิน Figma

เลือกเฟรม UI ใน Figma แล้วกด Generate ปลั๊กอินจะอ่านข้อความทุกจุด จัดประเภท (ปุ่ม · ป๊อปอัป · แท็บ · ว่าง · toast) แล้วเสนอข้อความใหม่ตามกติกา UX writing ของ PHCIS ให้เทียบก่อนกด "นำไปใช้" ทีละข้อ

น้ำเสียงไม่มีเพศ กติกาเดียวกับเว็บ ตรวจในเครื่อง · ไม่ส่งออก Generate ส่ง Claude API เมื่อกดยืนยัน

C · ใช้งานยังไง

install_desktopติดตั้งครั้งแรก

  1. เปิด Figma desktop → Plugins → Development → Import plugin from manifest…
  2. เลือก figma/plugin-ux-writing/manifest.json (หรือสำเนาบน Desktop)
  3. manifest เปลี่ยนเมื่อเพิ่ม Claude API → ถ้าเคย import ไว้ ให้ลบแล้ว import ใหม่

play_circleใช้ทุกครั้ง

  1. เลือกเฟรม UI → เปิด Plugins → Development → PHCIS · UX writing
  2. ปุ่ม API key → วาง key (สร้างที่ console.anthropic.com) ครั้งเดียว
  3. Generate UX writing → ยืนยัน → ดูตาราง → นำไปใช้
  4. ไม่อยากส่งออกนอกเครื่อง ใช้ ตรวจกติกาอย่างเดียว
