2.2 ข้อความต้นฉบับ

คณะ 9 HIV.pdf หน้า 2: "เปลี่ยนชื่องานรักปลอดภัย เป็น งานHIVและติดต่อทางเพศสัมพันธ์"
ชีต HIV-03 (MoM 9/2569 ข้อ 1.2.1 รับทราบ): "เปลี่ยนชื่อเมนูหลักจาก 'งานรักปลอดภัย' เป็น 'ระบบงาน HIV และโรคติดต่อทางเพศสัมพันธ์'" · ⚠ ชีตเขียน "ระบบงาน…" ส่วนบันทึกประชุมเขียน "งาน…" — ใช้ "งาน HIV และโรคติดต่อทางเพศสัมพันธ์" ตามบันทึกประชุมและชื่อหน้าคิว

2.3 วิธีเข้าไปดู

  1. เข้าด้วยบทบาท อายุรแพทย์โรคติดเชื้อ (คลินิกรักปลอดภัย)
  2. เมนูซ้าย "ห้องตรวจ" → แถวแรกใต้ "คิวรวมรอรับเคส" คือ "งาน HIV และโรคติดต่อทางเพศสัมพันธ์"
  3. เมนูคลังที่แถบซ้ายของบทบาทเดียวกัน ใช้ชื่อเดียวกัน

  2. ดูที่ขวาบนของหัวแฟ้ม ปุ่มเขียว "ขึ้นทะเบียนผู้ป่วยใหม่"

ลบช่อง "UIC code" ออกจากป๊อปอัปขึ้นทะเบียน (ทั้งในหน้าบันทึกและหน้าทะเบียนผู้รับบริการ) · ระบบเก็บรหัสอ้างอิงเป็น UIC- อัตโนมัติเบื้องหลัง เพื่อให้ตารางทะเบียนยังแสดงรหัสได้

2.2 ข้อความต้นฉบับ

คณะ 9 HIV.pdf หน้า 1: ภาพช่อง "UIC code*" (UIC-2545-01-30 · "รหัสที่ใช้แสดงแทนชื่อในตารางของคลินิก") ต่อท้าย "การขึ้นทะเบียน พยาบาลและหมอ → ตัดออก"
ผู้ใช้ตอบ 20 พ.ย. 69: "ตัดช่อง UIC code ใน popup ขึ้นทะเบียน"
⚠ ชีต HIV-13 ใช้ UIC เป็นรหัสผู้รับบริการ (Master ID) — ที่ประชุมรับทราบเท่านั้น จึงเก็บรหัสเบื้องหลังไว้

2.3 วิธีเข้าไปดู

  1. เข้าด้วยบทบาท อายุรแพทย์โรคติดเชื้อ → เมนู "ห้องตรวจ" → "งาน HIV และโรคติดต่อทางเพศสัมพันธ์"
  2. เปิดผู้ป่วยรายใหม่ HN 67-00028 (นายพงศ์ศักดิ์ แสงทอง) ที่ยังไม่ขึ้นทะเบียน
  3. เอาเมาส์ชี้ป้ายเทา "ไม่ขึ้นทะเบียน" ข้าง HN → กดปุ่ม "ขึ้นทะเบียนผู้ป่วยใหม่"
  4. ดูหัวข้อ "ข้อมูลทะเบียน" — ไม่มีช่อง UIC code แล้ว
