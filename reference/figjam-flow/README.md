## การตีความ (ใช้ในเอกสาร flow)

- "Kiosk พัง" กับ "คัดแยก เพิ่มคิวต่อแถว" ใช้ทางแยก "มีนัดหมาย?" ชุดเดียวกับ Kiosk
- "VN จะเปิดที่คัดแยก กรณี" = กรณี Kiosk พัง (ผู้ใช้ยืนยัน 23 ต.ค. 69)
- มีนัดหมาย → ข้ามคัดแยก ไปจุดที่นัดเลย · "แม้ว่านัดก็ต้องเข้าคัดแยกเสมอ" ไม่ใช้ (ผู้ใช้ยืนยัน 23 ต.ค. 69)
- "ถ้าพบแพทย์" (การเงิน → ตรวจ) = นัดทำหัตถการแล้วต้องพบแพทย์ด้วย ชำระก่อนแล้วไปตรวจ
- คัดแยกยังเป็นจุดแยก "มารับยาแทน" ตามกติกาเดิม (บอร์ดไม่ได้วาด)
