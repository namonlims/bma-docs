ที่มาของข้อมูล

ดึงจากโค้ดจริง ไม่ได้พิมพ์เอง

แหล่งข้อมูลและวิธีสร้างใหม่
  • Hub = การ์ดจาก hubSystemsForStaffRole(role) (6 ระบบ: PHCIS · ชุมชน · สุขภาพนักเรียน · คลังยา · ความยินยอม · จัดการระบบ) · ระบบที่ไม่มีการ์ดบน Hub (ตารางเวร · e-document · ประวัติการใช้งาน) ไม่แสดงในผังนี้
  • Sidebar + Sub sidebar = filterNavItemsForRole(withRegistryClinics(nav), role) (ชุดเดียวกับที่ Sidebar.jsx ใช้) · nav = PHCIS_SIDE_MENU · SYSTEM_NAV · AUDIT_NAV · EDOCUMENT_NAV · CONSENT_NAV · COMMUNITY_NAV · SCHOOL_SYSTEM_NAV · DRUG_NAV
  • Page / Tab = เปิดหน้าจริงบน localhost ด้วยบทบาทที่เห็นเมนูนั้น แล้วอ่าน [role=tablist] (TabUnderline · StickyStatusTabBar) · แท็บในป๊อปอัปไม่นับ · หัวหน้า = h1
  • บทบาท = ทุกค่าใน STAFF_ROLE_VIEWS (รวมบทบาทแยกงานสุขภาพจิต และบทบาท Mockup)
  • สร้างใหม่: สคริปต์ docs/sitemap-menu/extract.mjs + build.py (ดู README ในโฟลเดอร์)
