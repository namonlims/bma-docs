สร้าง design system

เข้าสู่ระบบด้วยบัญชี Google ของเจ้าของ แล้วหน้าสร้าง design system จะแสดงที่นี่

  • การตรวจสิทธิ์ทำที่ Studio ในเครื่องเจ้าของ ไม่ได้ทำที่หน้านี้
  • ข้อมูล ticket และไฟล์ที่อัปโหลดอยู่ในเครื่อง ไม่อยู่บนเว็บ
  • ถ้า Chrome ถามสิทธิ์เข้าถึงอุปกรณ์ในเครือข่ายภายใน ให้กด อนุญาต (ใช้เปิด Studio ในเครื่องคุณ)
  • ถ้าเปิดไม่ติด ให้รัน npm start ใน ticket-studio
