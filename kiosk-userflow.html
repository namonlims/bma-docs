UX notes

  • Tap target: ทั้งหน้าจอเป็น tap area เพื่อ accessibility ขั้นสูงสุด.
  • Visual cue: CTA button มี subtle pulse animation ดึงสายตา (ทุก 2 วินาที).
  • Brand presence: ใช้ gradient header เต็มที่ + facility identity ชัดเจน.
  • Language toggle: ติดมุมขวาบน — เลือกได้ก่อนเริ่ม.
  • Idle state: ถ้าไม่มี touch ใน 5 นาที → screensaver hidden (พื้นหลังเข้มลงเพื่อประหยัดพลังงาน).

5QUEUE TICKET

หน้าจอเดียวจบ: queue number + เวลารอ + 2 actions (print / QR). หลัง print/scan เสร็จ → "เสร็จสิ้น" → reset to welcome.

Action behaviors

  • พิมพ์บัตรคิว: POST → printer SDK. ติด feedback toast "กำลังพิมพ์…" 2s → "พิมพ์สำเร็จ ✓" 3s → auto-reset to welcome.
  • รับผ่าน QR: เปิด modal QR แบบ full-screen (ต่อด้านล่าง). กดที่ใดในมือถือเพื่อปิด.
  • Idle on this screen: 30s ไม่มี touch → auto-reset.

Queue number generation

  • Prefix per dept: A = OPD, B = ANC, C = Chronic, D = Dental, F = Finance, P = Pharmacy, L = Lab
  • 3-digit number, padded with zeros, increments per day · per dept.

📥 บันทึกภาพบัตรคิว

Image save behavior (mobile)

  • กด "บันทึกภาพ" → JS render ticket เป็น Canvas (800×1000px) → canvas.toBlob() → URL.createObjectURL → trigger download.
  • iOS Safari: ไฟล์ลง Files app · ต้อง long-press image กลางหน้าเพื่อ "Save to Photos".
  • Android Chrome: ไฟล์ลง Downloads · auto-show ใน Photos app.
  • Filename: queue-C-021-2025-05-25.png

🎨 UX principles

Touch targets

  • Min 64×64 px (Material recommendation 48 — but kiosk = larger).
  • Hit area expands 8 px beyond visual bounds.
  • Active state: scale(0.98) + ripple 200 ms.

Typography ladder

  • Page title: 36 px Bold
  • Sub-title: 24 px Medium
  • Card title: 30 px Bold
  • Card desc: 18 px Regular
  • Queue number: 100 px ExtraBold (Inter)

Color semantics

  • Brand green = selectable / primary action
  • Brand gradient = global header / branding accents
  • Warning amber = walk-in (no appointment)
  • Danger red = ID not found / failure
  • Neutral grey = secondary info / unfilled fields

Reset & timeouts

  • Step 0–2: 5-min idle → screensaver dim
  • Step 3–4: 60s idle → auto-reset (privacy)
  • Step 5: 30s post-print → auto-reset
  • "กลับสู่หน้าแรก" button visible bottom-right of all in-flow screens
